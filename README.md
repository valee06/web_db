# web_db — веб-интерфейс для учёта платежей по квартирам

Небольшое веб-приложение на Go поверх базы PostgreSQL: бухгалтерия жилого дома. Для каждого лицевого счёта (квартиры) ведутся начальное сальдо, начисления и оплаты, а отчёты — оборотная ведомость, карточка квартиры и список должников — строит сама база данных SQL-функциями. Приложение отвечает за формы ввода и отображение.

Это мой pet-проект: хотелось сделать законченный сервис без фреймворков — только стандартная библиотека и драйвер `pgx`.

## Что умеет

| Страница | Маршрут | Назначение |
| -------- | ------- | ---------- |
| Главная | `/` | навигация по разделам |
| Сальдо | `/saldo` | ввод начального сальдо по счёту за месяц (повторный ввод обновляет значение), таблица всех записей |
| Начисления | `/charges` | добавление начисления; дата по умолчанию — сегодня |
| Оплаты | `/payments` | добавление оплаты; дата по умолчанию — сегодня |
| Отчёты | `/reports` | меню отчётов |
| Оборотная ведомость | `/reports/turnover?year=` | по каждому счёту и месяцу: начислено, оплачено, сальдо; год по умолчанию — текущий |
| Карточка квартиры | `/reports/apartment?account=&year=` | помесячная таблица по выбранному счёту, итоги и сумма к оплате |
| Должники | `/reports/debtors?as_of=` | задолженность на дату по срокам: 1, 2, 3 месяца и более 3; дата по умолчанию — сегодня |

## Как это устроено

- **Только стандартная библиотека + `pgx`.** HTTP — `net/http`, страницы — `html/template`, пул соединений — `pgxpool`.
- **Шаблоны встроены в бинарник** через `embed`, поэтому для запуска достаточно одного файла. Общие части (`head`, `nav`, `flash`) вынесены в `layout.html`.
- **Отчёты считает база.** Приложение вызывает функции `report_turnover(year)`, `report_apartment(account, year)` и `report_debtors(as_of)` и только раскладывает результат по таблицам.
- **Деньги — строки.** Суммы читаются из базы как `amount::text` и не проходят через `float64` при отображении, поэтому копейки не теряются.
- **Валидация.** Год отчёта ограничен диапазоном 2000–2100, месяц передаётся как `YYYY-MM` и сохраняется первым числом месяца.
- **Сообщения об ошибках и успехе** показываются над формой.

## Таблицы и функции базы

Приложение ожидает следующие объекты:

| Объект | Поля / сигнатура |
| ------ | ---------------- |
| таблица `saldo` | `account_number`, `period`, `amount`; уникальность по `(account_number, period)` |
| таблица `charges` | `account_number`, `period`, `charge_date`, `amount` |
| таблица `payments` | `account_number`, `period`, `payment_date`, `amount` |
| функция `report_turnover(year)` | строки оборотной ведомости |
| функция `report_apartment(account, year)` | помесячная карточка квартиры |
| функция `report_debtors(as_of date)` | долги по срокам |

## Запуск

Нужны Go (версия из `go.mod`) и PostgreSQL с описанными выше таблицами и функциями.

```bash
export DATABASE_URL="host=/tmp dbname=accounting_department"   # значение по умолчанию
go run .
```

Приложение слушает порт `8080`: <http://localhost:8080>. Строка подключения берётся из переменной `DATABASE_URL`; если она не задана, используется локальное подключение через unix-сокет к базе `accounting_department`.
